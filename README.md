# Basic Full Screen Navigation

A full screen navigation menu that opens from a menu icon.

## What it demonstrates
- Full screen menu overlay with CSS
- Toggling an `active` class with a small JavaScript function
- Hover text effect using `data-text` and `content: attr(data-text)`

## Features
- Menu icon that opens and closes the menu
- Five links (Home, About, Services, Portfolio, Contact) next to a banner image
- Links are placeholders

## Tech
- HTML, CSS, vanilla JavaScript

## How to run
Open `index.html` in your browser.
